# Deploying Parichay on AWS EC2

## Architecture

```
Internet → Route 53 (DNS) → EC2 t3.small
                              ├── Nginx (port 80/443, SSL)
                              ├── Next.js app (port 3000)
                              ├── PostgreSQL 16 (port 5432)
                              └── Redis 7 (port 6379)
```

**Monthly cost: ~$16-18**
- EC2 t3.small: $15.33/mo
- Route 53: $0.50/mo
- S3 storage: ~$0.50/mo (file uploads)
- SSL: Free (Let's Encrypt)

## Prerequisites

- AWS account
- Domain name (pointed to Route 53 or any DNS)
- SSH key pair for EC2

## Step 1: Launch EC2 Instance

1. Go to AWS Console → EC2 → Launch Instance
2. Settings:
   - **AMI**: Ubuntu 22.04 LTS
   - **Instance type**: t3.small (2 vCPU, 2GB RAM)
   - **Storage**: 30GB gp3 (free tier covers 30GB)
   - **Security Group**: Allow ports 22 (SSH), 80 (HTTP), 443 (HTTPS)
   - **Key pair**: Select or create one

3. Note the public IP address after launch.

## Step 2: Point DNS

Add an A record in your DNS provider:
```
parichay.io      → <EC2_PUBLIC_IP>
www.parichay.io  → <EC2_PUBLIC_IP>
```

## Step 3: Run Setup Script

SSH into your instance and run:
```bash
ssh -i your-key.pem ubuntu@<EC2_IP>

# Download and run setup
curl -sSL https://raw.githubusercontent.com/your-repo/main/deploy/scripts/setup-ec2.sh | DOMAIN=parichay.io EMAIL=admin@parichay.io bash
```

This installs Docker, generates secrets, and prepares the environment.

## Step 4: Clone & Configure

```bash
cd /opt/parichay
git clone https://github.com/your-org/parichay.git .

# Edit production secrets (auto-generated by setup script)
nano .env.production
```

Fill in the API keys for Razorpay, SMTP, Google Maps, etc.

## Step 5: Get SSL Certificate

```bash
# Stop nginx temporarily if running
docker compose -f docker-compose.prod.yml down nginx 2>/dev/null || true

# Get certificate
sudo certbot certonly --standalone -d parichay.io -d www.parichay.io \
  --email admin@parichay.io --agree-tos --non-interactive

# Auto-renewal (add to crontab)
echo "0 3 * * * certbot renew --quiet --deploy-hook 'docker compose -f /opt/parichay/docker-compose.prod.yml restart nginx'" | sudo tee /etc/cron.d/certbot-renew
```

## Step 6: Deploy

```bash
/opt/parichay/deploy.sh
```

This builds the Docker image, starts all services, and runs database migrations.

## Step 7: Seed Initial Data (First Time Only)

```bash
# Run database seed
docker compose -f docker-compose.prod.yml exec app npx prisma db seed

# Create super admin
docker compose -f docker-compose.prod.yml exec app node -e "
const { prisma } = require('./node_modules/.prisma/client');
const bcrypt = require('bcryptjs');
(async () => {
  const hash = await bcrypt.hash('YourSecurePassword123!', 12);
  await prisma.user.create({
    data: {
      email: 'admin@parichay.io',
      passwordHash: hash,
      firstName: 'Super',
      lastName: 'Admin',
      role: 'SUPER_ADMIN',
      isActive: true,
      emailVerified: true,
    }
  });
  console.log('Super admin created!');
})();
"
```

## Ongoing Operations

### Deploy updates (after git push)
```bash
ssh ubuntu@<EC2_IP> "/opt/parichay/deploy.sh"
```
Or it runs automatically via GitHub Actions on push to `main`.

### View logs
```bash
docker compose -f docker-compose.prod.yml logs -f app      # App logs
docker compose -f docker-compose.prod.yml logs -f postgres  # DB logs
docker compose -f docker-compose.prod.yml logs -f nginx     # Nginx logs
```

### Database backup
```bash
# Manual backup
/opt/parichay/deploy/scripts/backup.sh

# Setup daily cron (2 AM)
echo "0 2 * * * /opt/parichay/deploy/scripts/backup.sh >> /var/log/parichay-backup.log 2>&1" | crontab -
```

### Restart services
```bash
docker compose -f docker-compose.prod.yml restart       # All
docker compose -f docker-compose.prod.yml restart app   # Just app
```

### Database access
```bash
docker compose -f docker-compose.prod.yml exec postgres psql -U parichay -d parichay_prod
```

## GitHub Actions (CI/CD)

The `.github/workflows/deploy.yml` auto-deploys on push to `main`.

Add these secrets to your GitHub repo (Settings → Secrets):
- `EC2_HOST`: Your EC2 public IP
- `EC2_USER`: `ubuntu`
- `EC2_SSH_KEY`: Contents of your .pem private key

## Monitoring

### Health check
```bash
curl https://parichay.io/api/health
```

### Resource usage
```bash
docker stats  # Live CPU/memory per container
df -h         # Disk usage
```

## Scaling Up (When Needed)

When you outgrow t3.small:
1. **Vertical**: Change to t3.medium ($30/mo) for 4GB RAM
2. **Managed DB**: Move PostgreSQL to RDS ($15/mo) for automated backups
3. **CDN**: Add CloudFront for static assets
4. **Managed Redis**: Move to ElastiCache ($13/mo)
